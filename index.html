Anthony WHOOP
Privacy Policy

Effective October 15, 2026 · Personal integration

Anthony WHOOP is a personal integration operated by the owner of the anthonyomorada GitHub account. It is intended for the operator's own WHOOP account and is not a public health service or an official WHOOP product. This policy describes the intended integration; publishing this page does not itself connect an account or retrieve health data.

Data accessed

With explicit WHOOP authorization, the integration may read recovery scores, heart rate variability, resting heart rate, physiological cycles and daily strain, sleep and sleep stages, and workouts. If separately authorized, it may also read profile information and body measurements. Only data covered by the permissions granted in WHOOP is accessed.

Purpose and processing

Data is used for personal tracking, trend analysis, and summaries through the operator's assistants, including Codex and G_Dub (Hermes). Selected records or summaries may be sent to the AI providers configured for those assistants when they are used for analysis. Those providers process information under their own terms and privacy policies. The integration does not sell health data or use it for advertising.

Storage and access

The intended primary store is on the operator's private computer or personal server. OAuth credentials and tokens are kept in private configuration, separate from this public site and its repository. The integration uses WHOOP authorization rather than collecting the WHOOP password. Access is limited to the operator and the services the operator authorizes. No security system can guarantee absolute protection.

Retention and deletion

Records are retained for personal longitudinal analysis until the operator deletes them. The operator can delete locally stored records and credentials. Copies in backups and assistant conversation histories must be removed separately through the relevant system; provider retention rules may also apply.

Revoking access

The operator can revoke the integration through WHOOP's connected-app controls. Revocation stops future authorized retrieval; it does not automatically delete previously stored records, backups, or assistant conversations.

This website

This page contains no health records, credentials, analytics scripts, or data-entry forms. It is hosted on GitHub Pages. GitHub may process standard request information, such as IP addresses, under the GitHub Privacy Statement.

Contact and changes

For privacy questions, contact the operator using the contact email displayed in the WHOOP app's developer registration. The operator's public identity is linked above. This policy will be updated if the integration's data handling changes.
